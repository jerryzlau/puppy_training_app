Brushing is cheek scratches with better hardware — if you introduce it that way. Let the cat sniff the brush, rub on it, claim it. Then use it exactly where they already like hands: cheeks, chin, head.

Extend to the back only when they lean into the cheek brushing. Short sessions. End before they end it, and the next session starts easier.

Long-haired cats need this as grooming; short-haired cats need it as bonding and shed control. Either way, it should never be a wrestling match.

⚠️ **cat tip:** if the brush gets the slow-stomp tail, switch to a softer tool — a grooming glove reads as petting to most skeptical cats.
